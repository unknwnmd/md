# IMC

Веб-приложение для прохождения и создания тестов. Работает полностью в браузере, без сервера и зависимостей. Все данные хранятся в localStorage.

## Возможности

- Встроенный тест «Фармакология 22» (15 вопросов)
- Редактор тестов: создание, редактирование, удаление, 2–6 вариантов ответа
- Импорт и экспорт тестов в формате .medq
- Избранные вопросы
- Таймер на весь тест и на каждый вопрос (по желанию)
- Светлая, тёмная и системная тема, 6 акцентных цветов
- Профили с аватаром и контактами (демо-аутентификация)
- Статистика, разбор ошибок, оценка 2–5
- Перемешивание вопросов и вариантов
- Режимы «ответ сразу» и «экзамен»
- Адаптивная вёрстка
- Автосохранение прогресса
- Без внешних зависимостей — один HTML-файл

Открыть index.html в браузере.

## Формат .imx

Файл .imx — бинарный контейнер:

- первые 4 байта — сигнатура IMX
- далее — gzip-сжатый JSON (если браузер не поддерживает CompressionStream, пишется обычный JSON)

Структура JSON:

    {
      "format": "imx.questions",
      "version": 1,
      "title": "Название теста",
      "questions": [
        {
          "q": "Текст вопроса",
          "a": ["Вариант 1", "Вариант 2", "Вариант 3"],
          "c": 0
        }
      ]
    }

Поля:

- format — фиксированная строка "imx.questions"
- version — версия формата
- title — название теста
- questions[].q — текст вопроса
- questions[].a — массив вариантов (2–6 строк)
- questions[].c — индекс правильного ответа

## Стек

- HTML5, CSS3 (custom properties, prefers-color-scheme)
- JavaScript (ES2020+, async/await, CompressionStream, crypto.subtle)
- localStorage для хранения данных
- SVG-спрайт для иконок и аватаров
- Без сборщиков и зависимостей

## Горячие клавиши

- 1–6 — выбрать вариант ответа
- ← / → — предыдущий / следующий вопрос
- Esc — закрыть модалку или боковую панель

## Поддержка браузеров

- Chrome / Edge 90+
- Firefox 113+ (без CompressionStream, .medq сохраняется без сжатия)
- Safari 16.4+
- Opera, Yandex Browser
- Мобильные Chrome и Safari

## Данные и безопасность

- Все данные хранятся только в localStorage браузера
- Пароли хэшируются через crypto.subtle (SHA-256) — это демо, не production-аутентификация
- Нет сетевых запросов, аналитики и трекеров
- Удалить все данные: DevTools → Application → Local Storage → ключи pharm22_*, либо «Очистить данные сайта» в браузере
